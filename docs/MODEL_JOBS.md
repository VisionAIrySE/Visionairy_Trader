XFMS discovery was reached successfully on November 4, 2026 Pacific time through its MCP endpoint. Its live tools expose discover, rank, pick and an estimate-first benchmark. Initial discovery is preserved privately in data/model_selection/xfms_discovery_initial.sse. This is a started discovery, not a shortlist, benchmark or selected model. No paid call or monitoring subscription was started.

| Job | Observable evaluation |
|---|---|
| News extraction / deduplication | Correct entity, event, publication/availability time and cited text; schema validity; duplicate handling; unknown fields stay unknown |
| Catalyst / conflicting evidence analysis | Supported conclusions, contradiction handling, uncertainty and no future-information leakage |
| Retrieval / embeddings | Relevant-source recall and citation identity on a labeled query set, with embedding and answer models evaluated separately |
| User explanations | Reconciles exactly to supplied account/decision facts; no invented numbers, opportunities or measured returns |

Each job needs its own primary and fallback assignment, model/provider/prompt versions, task-quality gate, measured latency, cost, failure rate and safe abstention. Actual workload and required latency remain to be measured; do not import another project's priorities or invent volume/budget terms. Current access, pricing and privacy must be verified before adoption. Benchmark offers require the quoted-cost decision before spending.

Scanning arithmetic, prices, sizing, risk limits, cash, settlement, fills and order authority stay in deterministic code. AI-assisted selection must also be compared with the same rule-based baseline on matched unseen evidence; a model benchmark alone cannot establish a return advantage.
