# Experiment plan

The target catalog is ten opportunity families with three entry styles, plus simple controls. It is not fully implemented.

Priorities:
1. Broad fresh percentage-price discovery, including formerly quiet stocks.
2. Price-only versus price plus unusual same-time-of-day activity.
3. Early entry, brief confirmation and retest.
4. Defined pullbacks, second waves, continuation/exhaustion.
5. Consistent baseline exits followed by explicit management comparisons.
6. Fixed-notional, risk-sized and staged-purchase tests; complete portfolios separately.
7. Add AI/news/peer features only if they improve simple baselines on later observations.

Historical replay precedes frozen forward ghost validation. Preserve failed bursts, missing data and unfillable opportunities. Do not tune and validate on the same window without disclosure.

All fills currently use explicitly assumed spreads/fees and observable bar timing; no historical bid/ask was supplied by the sampled endpoint. Scenarios sharing the same event are dependent.
