# Current session candidate evidence

A bounded hosted worker connects the saved broad quote coverage and current directory universe to current-session five-minute bars. It freezes up to twenty indicated common-share symbols by a session-specific hash before inspecting bars, prices or outcomes. This is a price-blind feed-qualification cohort, not full-market strategy discovery or a preferred ticker list.

The worker validates the provider's observed session calendar, bar OHLCV, minute slots and consistency between provider-local labels and UTC epochs. Incomplete/future bars are withheld, missing slots remain missing, and source payloads/hashes are retained. An observed offset of four/five hours is a consistency check, not independent certification of the provider's historical timezone/revision conventions. Corporate actions and full instrument eligibility remain unfinished.

The existing frozen independent detection specification processes completed bars. A final quote read retains bid and ask timestamps; receipt time and last-trade timestamps cannot substitute for executable-quote freshness. A final market-clock read captures transitions during collection. Closed-session evidence stays explicitly blocked. Pattern history is separate from current entry eligibility.

No target forecast or paper cash is invented. The remaining-opportunity and review adapter retains stale signals, missing target/quote evidence and unreconciled paper capital. Targets, liquidity capacity and shared risk/capital must be supported before allocation. The example policy cost values are research placeholders; without required evidence this path cannot reserve exposure or generate a qualified recommendation.

The authenticated API accepts only a fixed bounded session-probe start/stop action, runs outside the request thread, exposes progress and supports cancellation between bounded reads. Permission failures stop; ordinary per-symbol failures are retained as coverage gaps. Completed reports are immutable authenticated database records with verified content identity. Preparation/progress status and unsaved partial probe results are process-local; interrupted probes are not presented as completed captures. This stage does not implement restart/backfill for an unattended discovery service.

Local validation before release: 241 research/dashboard checks plus 7 sizing checks; JavaScript syntax passes. Tests cover bid/ask freshness, future quotes, incomplete bars, invalid clocks, sparse coverage, permission stop, cancellation and private bounded HTTP controls. Real hosted collection must be verified separately.

Continuous unattended operation, full-universe bar/strategy coverage, source-grounded live news and alert delivery remain unfinished. This change enables a concrete current-session feed test using existing read-only access; it creates no order path or new paid service.

Hosted verification on November 5, 2026 completed a price-blind twenty-symbol sample in 54 seconds. All twenty returned observed histories: 1,186 completed five-minute bars; ten full session histories and 374 missing slots across the other ten. The independent detector retained 18 breakout and 2 pullback-resumption patterns. The clock was postmarket and signals were stale; ranks remained unset and quantities zero. This is current-session feed evidence, not full-universe strategy coverage, valid current entry advice or financial performance. Retained report identity and authenticated paging were verified; invalid pages returned 400 and anonymous access 401. The historical candidate view, broad scanner and saved model assessment continued to respond.

The cancellation follow-up checks after final provider reads before saving a completed record; its focused test passes. User instructions require configurable simulation capital and do not prescribe a mandatory paper balance. This implementation therefore does not silently choose or infer paper cash from the tentative live funding amount.
